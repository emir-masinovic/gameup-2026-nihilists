# Kenney Nature Kit props

Two decorative rock models from Kenney Nature Kit 2.1, created/distributed by Kenney (https://kenney.nl/assets/nature-kit). License: CC0; original license included in LICENSE.txt. Attribution is optional under the supplied license; retained here for provenance.

Source files `Models/GLTF format/rock_smallA.glb` and `rock_smallB.glb` were copied as `rock_small_a.glb` and `rock_small_b.glb`. They contain embedded mesh/material data and no external textures. The central-assets source remains unchanged. These are decorative, non-colliding props; placement does not change the grid, tree placement, simulation RNG or passability.

Tree, dry/fall tree, stump, log and grass candidates were inspected but not imported. A later tree-focused pass should map foliage surfaces to climate states and verify base pivots before replacing the current deterministic falling-tree setup.
